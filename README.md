Removes the electron menu that pops up when you press alt.

## How to install

1. Clone the repository:

```bash
git clone git@github.com:OrderTheCat/freetube-patch.git && cd freetube-patch
```

2. Run the install.sh script:

```bash
./install.sh
```

The script will install the patched version of freetube and create another script which will auto update it.

**NOTE:** If you want auto updates, you need to keep the repository folder (freetube-patch).
